## Python - переменные

В Python переменные — это символические имена, которые ссылаются на объекты или значения, хранящиеся в памяти компьютера. Они позволяют присваивать данным описательные имена, упрощая манипулирование значениями и их повторное использование в коде. Для создания переменной в Python используется синтаксис `<variable>`, присваивающий ей значение `variable_name = value`.
