## Несколько групп операторов в виде наборов команд

В Python группы отдельных операторов, образующие единый блок кода, называются **наборами операторов (suites)**. Составные или сложные операторы, такие как if, while, def и class, требуют как заголовочной строки, так и набора операторов.

Заголовочные строки начинаются с ключевого слова и заканчиваются двоеточием (:), за ними следуют одна или несколько строк, составляющих набор команд. Например:

```python
if expression:
    suite
elif expression:
    suite
else:
    suite
```
