## Комментарии в Python

Комментарий — это понятное программисту пояснение или аннотация в исходном коде Python. Они добавляются с целью сделать исходный код более простым для понимания человеком и игнорируются интерпретатором Python.

Символ решетки (#), не являющийся строковым литералом, начинает комментарий. Все символы после # и до конца строки являются частью комментария, и интерпретатор Python их игнорирует.
```python
# First comment
print("Hello, World!")
# Second comment
```

Комментарий можно ввести на той же строке, что и оператор или выражение.

Строка, заключенная в тройные кавычки, также игнорируется интерпретатором Python и может использоваться в качестве многострочного комментария:

```python
'''
This is a multiline
comment.
'''
```
