## Рекомендации

Переменной всегда следует давать описательное имя, которое четко объясняет ее назначение. Иногда для названия переменной можно использовать одно слово:

```python
>>> temperature = 25
>>> weight = 54.5
>>> message = "Hello, Pythonista!"
```

Переменные всегда ссылаются на конкретные объекты, поэтому их имена должны быть существительными. Следует стараться найти для переменных конкретные имена, которые однозначно идентифицируют ссылаемый объект.
В целом, следует избегать однобуквенных имен. Конечно, есть исключения. Например, при работе с вложенными списками можно использовать однобуквенные имена для идентификации индексов:

```python
>>> matrix = [
...     [9, 3, 8],
...     [4, 5, 2],
...     [6, 4, 3],
... ]

>>> for i in matrix:
...     for j in i:
...         print(j)
...
9
3
8
4
5
2
6
4
3
```

Для обозначения индексов обычно используются буквы, такие как `i`, `j`, и `k`, поэтому их можно использовать в соответствующем контексте. Также для обозначения координат точек обычно используются `x`, `y`, и `z`, поэтому их тоже можно использовать.

Использование сокращений для именования переменных не рекомендуется; лучше использовать полное имя:

```python
>>> doc = "Freud"  # Don't do this
>>> doctor = "Freud"  # Do this instead
```

Однако иногда использование сокращений допустимо, если они широко распространены и используются:

```python
>>> cmd = "python -m pip list"
>>> msg = "Hello, Pythonista!"
```

В этих примерах — `cmd`это часто используемое сокращение для _команды_ , а `msg`— для _сообщения_ .

Иногда для создания описательного имени переменной требуется несколько слов. При использовании многословных имен их может быть сложно прочитать, если между словами нет четкой границы:

`>>> numberofgraduates = 200`

Название этой переменной сложно прочитать. Нужно внимательно следить за границами слов, чтобы понять, что обозначает эта переменная.

Наиболее распространенные методы использования многословных имен переменных следующие:

- **Змеиный регистр:** слова, написанные строчными буквами, разделяются подчеркиваниями. Например: `number_of_graduates`.
- **Верблюжий регистр:** второе и последующие слова пишутся с заглавной буквы, чтобы границы слов было легче увидеть. Например: `numberOfGraduates`.
- **Паскальский регистр:** Аналогичен верблюжьему регистру, за исключением того, что первое слово также пишется с заглавной буквы. Например: `NumberOfGraduates`.

Руководство [по стилю кода Python](https://www.python.org/dev/peps/pep-0008/) , также известное как **PEP 8** , содержит [правила именования](https://www.python.org/dev/peps/pep-0008/#naming-conventions) , в которых перечислены рекомендуемые стандарты для имен различных типов объектов. Что касается переменных, PEP 8 рекомендует использовать стиль _snake case_ .

Переменные-флаги — ещё один хороший пример того, когда следует использовать многословные имена переменных:

```python
>>> is_authenticated = True
>>> has_permission = False
```

В списках имен и словарях в большинстве случаев следует использовать существительные во множественном числе:

```python
>>> fruits = ["apple", "banana", "cherry"]

>>> colors = {
...     "Red": (255, 0, 0),
...     "Green": (0, 255, 0),
...     "Blue": (0, 0, 255),
...     "Yellow": (255, 255, 0),
...     "Black": (0, 0, 0),
...     "White": (255, 255, 255),
... }
```

При именовании кортежей следует учитывать, что они обычно используются для хранения объектов разных типов или значений. Поэтому допустимо использовать существительные в единственном числе:

```python
>>> color = (255, 0, 0)
>>> row = ("Jane", 25, "Python Dev", "Canada")
```
