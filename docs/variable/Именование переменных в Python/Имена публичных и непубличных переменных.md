## Непубличные переменные

В Python широко используется соглашение об именовании переменных, когда необходимо указать, что данная переменная является так называемой непубличной (non-public) переменной. Непубличная переменная — это переменная, которую не следует использовать за пределами модуля, в котором она была создана. Такие переменные предназначены только для внутреннего использования:

```python
_timeout = 30

def get_timeout():
    return _timeout

def set_timeout(seconds):
    global _timeout
    _timeout = seconds
```

В этом модуле есть непубличная переменная с именем ` `timeout`.`. Затем у вас есть пара функций, которые работают с этой переменной. Однако сама переменная не предназначена для использования за пределами содержащего её модуля.
