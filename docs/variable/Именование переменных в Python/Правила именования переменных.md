## Именования

В Python имена переменных могут быть любой длины и состоять из заглавных ( `A-Z`) и строчных ( `a-z`), цифр ( `0-9`) и символа подчеркивания ( `_`). Единственное ограничение заключается в том, что, хотя имя переменной может содержать цифры, ==**первый символ имени переменной не может быть цифрой**==.

```python
>>> name = "Bob"
>>> year_of_birth = 1970
>>> is_adult = True
```

Важно знать, что переменные чувствительны к регистру. Строчные и прописные буквы обрабатываются по-разному:

```python
>>> age = 1
>>> Age = 2
>>> aGe = 3
>>> AGE = 4

>>> age
1
>>> Age
2
>>> aGe
3
>>> AGE
4
```

Использование символов [подчеркивания](https://realpython.com/python-double-underscore/) также имеет важное значение. Подчеркивание используется для разделения нескольких слов в имени переменной:

```python
>>> first_name = "John"
>>> pen_color = "red"
>>> next_node = 123
```

Это способ улучшить читаемость кода, заменив пробел символом подчеркивания.
