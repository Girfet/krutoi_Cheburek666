[[variable (Переменные)]]
---
Теги: #python #variable 


В Python зарезервирован небольшой набор слов, известных как ключевые слова , которые являются частью синтаксиса языка. Чтобы получить список ключевых слов Python, выполните следующий код:

```python
>>> import keyword
>>> keyword.kwlist
[
    'False',
    'None',
    'True',
    'and',
    'as',
    'assert',
    'async',
    ...,
    'yield'
]
```

В большинстве случаев вы не сможете использовать эти слова в качестве имен переменных без возникновения ошибки.

Если вам нужно использовать имя, совпадающее с ключевым словом, вы можете следовать рекомендации PEP 8, а именно добавить к имени завершающее подчеркивание:

```python
>>> class_ = "Business"
```

 Хотя этот способ работает, иногда элегантнее поступить следующим образом:

```python
>>> passenger_class = "Business"
```

Теперь имя вашей переменной стало гораздо более описательным и конкретным, что улучшает читаемость кода.

Существуют также так называемые «мягкие ключевые слова» , которые являются ключевыми словами только в определённых контекстах. Например, `match`ключевое слово считается ключевым словом только при сопоставлении структурных шаблонов.

Поскольку `match`это мягкое ключевое слово, его можно использовать для именования переменных:

```python
>>> import re

>>> text = "Some text containing a number: 123"
>>> match = re.search("123", text)

>>> if match:
...     print("Found a match 😃")
... else:
...     print("No match found 😔")
...
Found a match 😃
```

Ещё одна практика, которой следует избегать, — это использование встроенных имен для именования переменных:

```python
>>> list = [1, 2, 3, 4]
>>> list
[1, 2, 3, 4]
```

В этом примере вы использовали `list`в качестве имени для `list`объекта, содержащего числовые значения. Это перекрывает исходный объект, находящийся за этим именем, что не позволяет использовать его в вашем коде.


Обратите внимание, что эта рекомендация также действительна для имен, которые ссылаются на объекты, определенные в сторонних библиотеках, используемых вами в коде.
