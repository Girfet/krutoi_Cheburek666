##  Переменные содержат ссылки на объекты

Переменная в Python — это символическое имя, которое ссылается на объект, например, ` `300`.`. После того как объект присвоен переменной, вы можете обращаться к ней по имени переменной, но сами данные по-прежнему содержатся внутри объекта.

```python
>>> n = 300
```

![Присваивание переменных](https://realpython.com/cdn-cgi/image/width=636,format=auto/https://files.realpython.com/media/t.2d7bcb9afaaf.png)

В Python переменные не хранят объекты. Они указывают на объекты или ссылаются на них. Каждый раз, когда вы создаете объект в Python, ему присваивается уникальный номер, который затем связывается с переменной.

Встроенная `id()` функция возвращает идентификатор или идентичность объекта:

```python
>>> n = 300
>>> id(n)
4399012816
```

В CPython стандартной дистрибуции Python, идентификатор объекта совпадает с его адресом в памяти. Поэтому переменные CPython _хранят адреса в памяти_ . Через эти адреса переменные получают доступ к конкретным объектам, хранящимся в памяти.

Вы можете создать несколько переменных, указывающих на один и тот же объект. Другими словами, переменные, хранящие один и тот же адрес в памяти.

```python
>>> m = n
>>> id(n) == id(m)
True
```

![Множественные ссылки на один и тот же объект](https://realpython.com/cdn-cgi/image/width=1083,format=auto/https://files.realpython.com/media/t.d368386b8423.png)


Далее, предположим, вы делаете что-то подобное:

```python
>>> m = 400
```

Теперь Python создает новый целочисленный объект со значением `400`и `m`становится ссылкой на него:

![Ссылки на отдельные объекты](https://realpython.com/cdn-cgi/image/width=1083,format=auto/https://files.realpython.com/media/t.d476d91592cd.png)

Наконец, предположим, вы выполнили следующее выражение:

```python
>>> n = "foo"
```

Теперь Python создает строковый объект со значением `"foo"`и `n`ссылается на него:

![Осиротевший объект](https://realpython.com/cdn-cgi/image/width=1083,format=auto/https://files.realpython.com/media/t.344ab0b3aa8c.png)

Из-за `n`переназначений `m`у вас больше нет ссылки на целочисленный объект `300`. Он стал "осиротевшим", и у вас нет возможности снова получить к нему доступ.

Когда количество ссылок на объект становится равным нулю, объект становится недоступным. В этот момент его время жизни истекает. Python освобождает выделенную память, чтобы её можно было использовать для чего-то другого. В терминологии программирования этот процесс известен как сборка мусора.


## Переменные имеют динамические типы

Во многих языках программирования переменные имеют **статическую типизацию** , что означает, что изначально они объявляются с определенным типом данных на протяжении всего своего существования. Любое значение, присвоенное этой переменной в течение ее существования, должно иметь указанный тип данных.

В Python переменные не имеют такой типизации. В Python можно присваивать переменной значения разных типов данных в разные моменты времени:

```python
>>> value = "A string value"
>>> value
'A string value'

>>> # Later
>>> value = 23.5
>>> value
23.5
```

Важно отметить, что изменения типа данных переменной могут привести к ошибкам во время выполнения. Например, если тип данных переменной изменится неожиданно, вы можете столкнуться с ошибками, связанными с типом, или даже получить исключение.

## Переменные могут использовать подсказки типа

Для добавления явной информации о типе к вашим переменным можно использовать подсказки типов. Для этого можно использовать следующий синтаксис Python:

```python
variable: data_type [= value]
```

Квадратные скобки не являются частью синтаксиса. Они указывают на то, что заключенная в них часть необязательна. Да, вы можете объявить переменную Python, не присваивая ей значение:

```python
>>> number: int

>>> number
Traceback (most recent call last):
    ...
NameError: name 'number' is not defined
```

Объявление переменной в первой строке работает и является допустимым синтаксисом Python. Однако это объявление на самом деле не создает новую переменную. Поэтому при попытке доступа к переменной `number`возникает `NameError`исключение. Даже несмотря на то, что переменная `number`не определена, Python зафиксировал подсказку типа:

```python
>>> __annotations__
{'number': <class 'int'>}
```

 Но нет смысла добавлять подсказки, когда имеете дело с базовыми типами данных, таких как числа, строки и числа с плавающей точкой.
 
Ситуация меняется при использовании типов коллекций, таких как списки, кортежи, словари и множества. В случае с этими типами имеет смысл указывать подсказки типов для содержащихся в них данных.

```python
>>> colors: dict[str, str] = {
...     "red": "#FF0000",
...     "green": "#00FF00",
...     "blue": "#0000FF",
...     "yellow": "#FFFF00",
...     "black": "#000000",
...     "white": "#FFFFFF",
... }
```

Важно отметить, что указание типа для переменных, ссылающихся на типы данных контейнера, особенно полезно при инициализации переменной пустым контейнером:

```python
>>> fruits: list[str] = []
>>> rows: list[tuple[str, int, str]] = []
```
