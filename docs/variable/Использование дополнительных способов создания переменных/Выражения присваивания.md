[[variable (Переменные)]]
---
Теги: #python #variable 


Выражения присваивания позволяют за один шаг присвоить результат выражения, используемого в условном операторе или `while`цикле, имени. Например, рассмотрим следующий цикл, который принимает ввод с клавиатуры до тех пор, пока вы не введете слово `"stop"`:

```python
>>> line = input("Type some text: ")

>>> while line != "stop":
...     print(line)
...     line = input("Type some text: ")
...
Type some text: Python
Python
Type some text: Walrus
Walrus
Type some text: stop
```

Цикл можно переписать, используя выражение присваивания, и в результате получится следующий код:

```python
>>> while (line := input("Type some text: ")) != "stop":
...     print(line)
...
Type some text: Python
Python
Type some text: Walrus
Walrus
Type some text: stop
```

В выражении `(line := input("Type some text: "))`вы создаете новую переменную с именем, `line`которая хранит ссылку на входные данные. Эти данные также возвращаются в качестве результата выражения, который в конечном итоге сравнивается со `"stop"`словом для завершения цикла.
