[[variable (Переменные)]]
---
Теги: #python #variable 


В Python также можно выполнять несколько присваиваний в одной строке кода. Эта функция позволяет одновременно присваивать одно и то же значение нескольким переменным:

```python
>>> is_authenticated = is_active = is_admin = False

>>> is_authenticated
False
>>> is_active
False
>>> is_admin
False
```

Использование параллельных присваиваний вместо отдельных присваиваний делает ваш код более лаконичным и менее повторяющимся.
