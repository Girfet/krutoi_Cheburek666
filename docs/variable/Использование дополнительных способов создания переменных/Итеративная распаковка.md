[[variable (Переменные)]]
---
Теги: #python #variable 


Распаковка итерируемых объектов — это интересная функция Python, также известная как **распаковка кортежей** . Она заключается в распределении значений итерируемого объекта по ряду переменных. В большинстве случаев количество переменных будет соответствовать количеству элементов в итерируемом объекте. Однако вы также можете использовать этот `*variable`синтаксис для получения нескольких элементов из списка.

Вы можете использовать распаковку итерируемых объектов для создания нескольких переменных одновременно, используя итерируемый объект значений.Например, предположим, у вас есть данные о человеке, и вы хотите создать отдельные переменные для каждого элемента данных:

```python
>>> person = ("Jane", 25, "Python Dev")
```

Можно воспользоваться итерационной распаковкой и получить следующий код:

```python
>>> name, age, job = person

>>> name
'Jane'
>>> age
25
>>> job
'Python Dev'
```
