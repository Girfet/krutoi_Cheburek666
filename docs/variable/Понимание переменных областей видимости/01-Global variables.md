## Глобальные переменные

**Глобальные переменные** — это переменные, которые вы создаете на уровне модуля. Эти переменные видны внутри содержащего их модуля и в других модулях, которые их импортируют. Например, если вы используете [REPL](https://realpython.com/python-repl/) Python , то текущая глобальная область видимости определена в модуле с именем `<module>` [`__main__`](https://docs.python.org/3/library/__main__.html#module-__main__).

Этот модуль определяет вашу текущую глобальную область видимости. Все переменные, определенные в этом модуле, являются глобальными, поэтому вы можете использовать их в любое время во время интерактивной сессии:

```python
>>> value = 42
>>> dir()
[
    '__builtins__',
    '__doc__',
    '__loader__',
    '__name__',
    ...
    'value'
]
```

В этом фрагменте кода вы определяете `value`переменную и вызываете встроенную [`dir()`](https://realpython.com/python-built-in-functions/#checking-names-and-attributes-dir-and-vars)функцию для проверки списка имен, определенных в текущей глобальной области видимости. В конце списка вы найдете запись `'value'`, соответствующую вашей переменной.
