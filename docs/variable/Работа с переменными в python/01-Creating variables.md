## Создание переменных

Основной способ создания переменной в Python — это **присвоение** ей значения с помощью оператора присваивания и следующего синтаксиса:

```python
variable_name = value
```

В этом синтаксисе слева указывается имя переменной, затем `=`оператор присваивания ( ), а после него — значение, которое вы хотите присвоить этой переменной. Значением в этой конструкции может быть любой объект Python, включая строки, числа, списки, словари или даже пользовательские объекты.
