## Временные переменные

Временные переменные хранят промежуточные результаты, необходимые для более сложных вычислений. Классический пример использования временной переменной — это необходимость обмена значениями между переменными:

```python
>>> a = 5
>>> b = 10

>>> temp = a
>>> a = b
>>> b = temp

>>> a
10
>>> b
5
```

В этом примере вы используете временную переменную с именем `temp`для хранения значения переменной, `a`чтобы можно было обменивать значения между `a`и `b`. После обмена переменная `temp`больше не нужна.
