## Переменные цикла

Переменные циклов помогают обрабатывать данные во время итерации в for циклах и while циклах. в for цикле переменная каждый раз принимает значение текущего элемента во входном итерируемом объекте при прохождении цикла:

```python
>>> colors = [
...     "red",
...     "orange",
...     "yellow",
...     "green",
...     "blue",
...     "indigo",
...     "violet"
... ]

>>> for color in colors:
...     print(color)
...
red
orange
yellow
green
blue
indigo
violet
```

В этом примере перебираются цвета в списке colors с помощью for цикла. переменная этого цикла color хранит в себе текущий цвет в каждой итерации 

Так же for циклы могут содержать несколько переменных. Например если нам нужно сопоставить цвет с его индексом:

```python
>>> for index, color in enumerate(colors):
...     print(index, color)
...
0 red
1 orange
2 yellow
3 green
4 blue
5 indigo
6 violet
```

здесь мы используем встроенную функцию enumerate() , для того, чтобы она генерировала индекс при итерации по входным данным. Для указания нескольких переменных цикла используется последовательность переменных, разделенных запятыми.

Для управления циклами также можно использовать переменные `while`. Вот простой пример:

```python
>>> count = 5

>>> while count:
...     print(count)
...     count -= 1
...
5
4
3
2
1
```

В этом примере переменная count используется как счётчик, который определяет количество итераций.
