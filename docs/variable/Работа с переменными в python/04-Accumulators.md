## Аккумуляторы

Аккумулятор — это переменная, которая используется для сложения последовательных значений с целью получения итоговой суммы, которую можно использовать в качестве промежуточного шага в различных вычислениях.

```python
>>> numbers = [1, 2, 3, 4]
>>> total = 0

>>> for number in numbers:
...     total += number
...

>>> total
10
```

В этом примере цикл перебирает список чисел и накапливает каждое значение в `total`. Вы также можете использовать аккумуляторы в качестве частей более сложных вычислений, например, для вычисления среднего значения списка чисел:

```python
>>> total / len(numbers)
2.5
```
