## Счетчики объектов

Счетчик — это целочисленная переменная, позволяющая подсчитывать количество объектов. Счетчики обычно имеют начальное значение, равное нулю, которое увеличивается, отражая количество появлений данного объекта.

```python
str_counter = 0

>>> for item in ("Alice", 30, "Programmer", None, True, "Department C"):
...     if isinstance(item, str):
...          str_counter += 1
...

>>> str_counter
3
```

В этом примере вы создаёте `str_counter`переменную, инициализируя её значением ` `0`.`. Затем вы запускаете `for`цикл по списку объектов разных типов. Внутри цикла вы проверяете, является ли текущий объект строкой, используя встроенную `isinstance()`функцию. Если текущий объект является строкой, то вы увеличиваете счётчик на единицу.
