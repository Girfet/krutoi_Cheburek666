## Переменные хранения данных

Переменные для хранения данных позволяют работать с контейнерами значений, такими как списки, кортежи, словари или множества.

```python
>>> contacts = [
...     ("Linda", "111-2222-3333", "linda@example.com"),
...     ("Joe", "111-2222-3333", "joe@example.com"),
...     ("Lara", "111-2222-3333", "lara@example.com"),
...     ("David", "111-2222-3333", "david@example.com"),
...     ("Jane", "111-2222-3333", "jane@example.com"),
... ]
```

Вы можете использовать переменные в цикле, например:

```python
>>> for contact in contacts:
...     print(contact)
...
('Linda', '111-2222-3333', 'linda@example.com')
('Joe', '111-2222-3333', 'joe@example.com')
('Lara', '111-2222-3333', 'lara@example.com')
('David', '111-2222-3333', 'david@example.com')
('Jane', '111-2222-3333', 'jane@example.com')

>>> for name, phone, email in contacts:
...     print(phone, name)
...
111-2222-3333 Linda
111-2222-3333 Joe
111-2222-3333 Lara
111-2222-3333 David
111-2222-3333 Jane
```

Первый цикл перебирает элементы в списке контактов и выводит их в виде кортежей. Второй цикл использует три переменные цикла для обработки каждого элемента данных по отдельности.


### Пометка

Вам не обязательно использовать все переменные или в том же порядке. Если у вас есть неиспользуемая переменная, то следует указать, что это переменная, которую нужно просто выбросить ( или использовать повторно), добавив к её имени нижнее подчеркивание .

Таким образом, заголовок цикла можно переписать следующим образом: `for name, phone, _ in contacts:`. В этом случае нижнее подчеркивание обозначает переменную email, которую вы не используете в теле цикла.
