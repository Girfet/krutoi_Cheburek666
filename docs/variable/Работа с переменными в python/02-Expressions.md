### Выражения

В Python выражение — это простое утверждение, которое Python может оценить и получить значение.

```python
>>> 2 * 3.1416 * 10
62.912
```

Сначала мы можем определить переменные для для хранения входных значений. Затем эти переменные используются в выражениях.

```python
>>> pi = 3.1416
>>> radius = 10

>>> 2 * pi * radius
62.912
```

Переменные отлично подходят для повторного использования значений в выражениях и выполнения вычислений с данными, которые изменяются со временем.
