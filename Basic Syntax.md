## Python - Синтаксис

Синтаксис Python определяет набор правил, используемых для создания программы на Python.

### Python — интерактивный режим программирования

Мы можем запустить [интерпретатор Python](https://www.tutorialspoint.com/online_python_compiler.php) из командной строки, набрав команду **`python`** в командной строке следующим образом:
```
$ python3 Python 3.10.6 (main, Mar 10 2023, 10:55:28) [GCC 11.3.0] on linux Type "help", "copyright", "credits" or "license" for more information. >>>
```

### Python — программирование в режиме скрипта

Мы можем вызвать [интерпретатор Python](https://www.tutorialspoint.com/python/python_interpreter.htm) с параметром script, который запускает выполнение скрипта и продолжается до его завершения. После завершения выполнения скрипта интерпретатор перестаёт быть активным.

Напишем простую программу на Python в скрипте, который представляет собой простой текстовый файл. Файлы Python имеют расширение **.py** .

## Идентификаторы Python

Идентификатор в Python — это имя, используемое для идентификации [переменной](https://www.tutorialspoint.com/python/python_variables.htm) , [функции](https://www.tutorialspoint.com/python/python_functions.htm) , [класса](https://www.tutorialspoint.com/python/python_object_classes.htm) , [модуля](https://www.tutorialspoint.com/python/python_modules.htm) или другого объекта. Идентификатор начинается с буквы от A до Z или от a до z, либо с символа подчеркивания ( \_ ), за которым следует ноль или более букв, символов подчеркивания и цифр (от 0 до 9).

В Python не допускаются знаки препинания, такие как @, $ и %, внутри идентификаторов.

> Python — это язык программирования, чувствительный к регистру. Таким образом, **Manpower** и **manpower** — это два разных идентификатора в Python.

Вот правила именования идентификаторов в Python:

- Названия классов Python начинаются с заглавной буквы. Все остальные идентификаторы начинаются со строчной буквы.
    
- Начало идентификатора с одного символа подчеркивания указывает на то, что это **закрытый** идентификатор.
    
- Идентификатор, начинающийся с двух символов подчеркивания, указывает на строго **конфиденциальный** идентификатор.
    
- Если идентификатор также заканчивается двумя завершающими подчеркиваниями, то это специальное имя **, определенное в языке** программирования .

## Строки и отступы в Python

Блоки кода обозначаются **отступом строки** , который строго соблюдается.
Количество пробелов в отступе может варьироваться, но все операторы внутри блока должны иметь одинаковый отступ.


## Многострочные операторы Python

В Python операторы обычно заканчиваются новой строкой. Однако Python допускает использование символа продолжения строки (\\) для обозначения того, что строка должна продолжаться. Например:

```python
total = item_one + \ 
        item_two + \
        item_three
```

Операторы, заключенные в квадратные скобки \[], {} или (), не обязательно должны использовать символ продолжения строки.

## Цитаты в Python

В Python для обозначения строковых литералов принимаются одинарные ('), двойные (") и тройные (''' или "") кавычки, при условии, что кавычки одного типа начинают и заканчивают строку.

Тройные кавычки используются для того, чтобы строка занимала несколько строк.

```python
word = 'word' 
print (word) 

sentence = "This is a sentence." 
print (sentence) 

paragraph = """This is a paragraph. It is made up of multiple lines and sentences.""" 
print (paragraph)
```

## Комментарии в Python

Комментарий — это понятное программисту пояснение или аннотация в исходном коде Python. Они добавляются с целью сделать исходный код более простым для понимания человеком и игнорируются интерпретатором Python.

Символ решетки (#), не являющийся строковым литералом, начинает комментарий. Все символы после # и до конца строки являются частью комментария, и интерпретатор Python их игнорирует.
```python
# First comment 
print ("Hello, World!") 
# Second comment
```

Комментарий можно ввести на той же строке, что и оператор или выражение.

Строка, заключенная в тройные кавычки, также игнорируется интерпретатором Python и может использоваться в качестве многострочного комментария:

```python
''' 
This is a multiline
comment. 
'''
```

## Использование пустых строк в программах на Python

Строка, содержащая только пробелы, возможно, с комментарием, называется пустой строкой, и Python её полностью игнорирует.

В интерактивном интерпретаторе для завершения многострочного оператора необходимо ввести пустую физическую строку.


## Ожидание пользователя

Следующая строка программы отображает приглашение, сообщение «Нажмите клавишу Enter для выхода» и ожидает действий от пользователя.
```python
raw_input("\n\nPress the enter key to exit.")
```

Здесь символ "\n\n" используется для создания двух новых строк перед отображением фактической строки.

## Несколько утверждений в одной строке

Точка с запятой ( ; ) позволяет размещать несколько операторов на одной строке при условии, что ни один из них не начинает новый блок кода.

```python
import sys; x = 'foo'; sys.stdout.write(x + '\n')
```


## Несколько групп операторов в виде наборов команд.

В Python группы отдельных операторов, образующие единый блок кода, называются **наборами операторов (suites** ). Составные или сложные операторы, такие как if, while, def и class, требуют как заголовочной строки, так и набора операторов.

Заголовочные строки начинаются с ключевого слова и заканчиваются двоеточием ( : ), за ними следуют одна или несколько строк, составляющих набор команд. Например:

```python
if expression : 
    suite 
elif expression : 
    suite 
else : 
    suite
```
